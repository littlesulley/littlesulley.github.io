Yesterday I watched Freya’s new video about lerp smoothing and it reminded me of the damping implementation of Cinemachine to control camera motion smoothly. In this blog post, I will give you more perspectives to understand the framerate-independent interpolation other than the ones deduced from Freya’s video.

Frame-Dependent Interpolation

Let’s first recap the frame-dependent interpolation. Let aaa be the source position, bbb the target position, and w∈[0,1]w\in[0,1]w∈[0,1] is a fixed value representing the ratio aaa will go through towards bbb, and ana_nan​ be the current position after nnn iterations (frames). The update equation is:

an=lerp(an−1,b,w)=(1−w)an−1+wba_n=\text{lerp}(a_{n-1}, b, w)=(1-w) a_{n-1}+w b an​=lerp(an−1​,b,w)=(1−w)an−1​+wb

with a0=aa_0=aa0​=a being the original source position. We can recursively expand this equation:

an=(1−w)an−1+wb=(1−w)((1−w)an−2+wb)+wb=(1−w)2an−2+w(1−w)b+wb=⋯=(1−w)na+w(1+(1−w)+⋯+(1−w)n−1)b=(1−w)na+(1−(1−w)n)b=lerp(a,b,1−(1−w)n)\begin{aligned} a_n &= (1-w) a_{n-1}+w b\\ &= (1-w)\left((1-w)a_{n-2}+wb\right)+wb\\ &=(1-w)^2a_{n-2}+w(1-w)b+wb\\ &=\cdots\\ &=(1-w)^na+w\left(1+(1-w)+\cdots+(1-w)^{n-1}\right)b\\ &=(1-w)^na+\left(1-(1-w)^n\right)b\\ &=\text{lerp}(a,b,1-(1-w)^n) \end{aligned} an​​=(1−w)an−1​+wb=(1−w)((1−w)an−2​+wb)+wb=(1−w)2an−2​+w(1−w)b+wb=⋯=(1−w)na+w(1+(1−w)+⋯+(1−w)n−1)b=(1−w)na+(1−(1−w)n)b=lerp(a,b,1−(1−w)n)​

It is obvious that ana_nan​ is dependent on nnn, which generally represents the frames per second (FPS). n=30n=30n=30 and n=60n=60n=60 produce significantly different results.

Frame-Independent Interpolation

The naive interpolation is frame-dependent because it’s updated based on the unit of frames, rather than seconds. We would like the interpolation function f(t)f(t)f(t), if lerp\text{lerp}lerp is generalized to lerp(a,b,f(t))\text{lerp}(a,b,f(t))lerp(a,b,f(t)), is only dependent on the elapsed time ttt rather than the frame rate.

Freya has given an interpretation to solve f(t)f(t)f(t) in her video. In the following sections I will give three more perspectives of understanding and solving f(t)f(t)f(t).

Perspective #1: Solving the Function Equation

What we need is: for any t>0t>0t>0 and any n∈Z+n\in\mathbb{Z}_+n∈Z+​, the following equation holds:

an=lerpn(a,b,f(t/n))=lerp(a,b,f(t))a_n=\text{lerp}_n(a,b,f(t/n))=\text{lerp}(a,b,f(t)) an​=lerpn​(a,b,f(t/n))=lerp(a,b,f(t))

This equation means that at any timestamp ttt, no matter how many pieces we segment ttt into, the accumulated interpolation result is always equal to the one without segmentation. nnn is the number of segments and lerpn\text{lerp}_nlerpn​ is applying lerp\text{lerp}lerp sequentially nnn times.

We can derive ana_nan​ explicitly:

an=(1−f(tn))na+(1−(1−f(tn))n)ba_n=\left(1-f\left(\frac{t}{n}\right)\right)^na+\left(1-\left(1-f\left(\frac{t}{n}\right)\right)^n\right)b an​=(1−f(nt​))na+(1−(1−f(nt​))n)b

Having it equal to lerp(a,b,f(t))\text{lerp}(a,b,f(t))lerp(a,b,f(t)):

1−f(t)=(1−f(tn))n, ∀t>0 ∀n∈Z+1-f(t)=\left(1-f\left(\frac{t}{n}\right)\right)^n,~\forall t>0~\forall n\in\mathbb{Z}_+ 1−f(t)=(1−f(nt​))n, ∀t>0 ∀n∈Z+​

Let’s prove that f(t)f(t)f(t) must be an exponential function, assuming f(t)∈C1f(t)\in C^1f(t)∈C1.

First, we rewrite the above funciton equation to:

1−f(nt)=(1−f(t))n, ∀t>0 ∀n∈Z+⇒1−f(t)=(1−f(nt))1/n, ∀t>0 ∀n∈Z+⇒1−f(t)=(1−f(tn))n, ∀t>0 ∀n∈1/Z+\begin{aligned} 1-f(nt)&=\left(1-f\left(t\right)\right)^n,~\forall t>0~\forall n\in\mathbb{Z}_+\\ \Rightarrow 1-f(t)&=\left(1-f(nt)\right)^{1/n},~\forall t>0~\forall n\in\mathbb{Z}_+\\ \Rightarrow 1-f(t)&=\left(1-f\left(\frac{t}{n}\right)\right)^n,~\forall t>0~\forall n\in1/\mathbb{Z}_+ \end{aligned} 1−f(nt)⇒1−f(t)⇒1−f(t)​=(1−f(t))n, ∀t>0 ∀n∈Z+​=(1−f(nt))1/n, ∀t>0 ∀n∈Z+​=(1−f(nt​))n, ∀t>0 ∀n∈1/Z+​​

This means that the original equation also holds for n∈1/Z+n\in1/\mathbb{Z}_+n∈1/Z+​.

We also have:

1−f(pqt)=1−f(ptq)=(1−f(tq))p=(1−f(t))pq, ∀t>0 ∀p,q∈Z+\begin{aligned} 1-f\left(\frac{p}{q}t\right) &= 1-f\left(p\frac{t}{q}\right)\\ &= \left(1-f\left(\frac{t}{q}\right)\right)^p\\ &= \left(1-f\left(t\right)\right)^\frac{p}{q},~\forall t>0~\forall p,q\in\mathbb{Z}_+ \end{aligned} 1−f(qp​t)​=1−f(pqt​)=(1−f(qt​))p=(1−f(t))qp​, ∀t>0 ∀p,q∈Z+​​

This means that the original equation also holds for n∈Q+n\in\mathbb{Q}_+n∈Q+​. We can prove it further holds for n∈R+n\in\mathbb{R}_+n∈R+​ by leveraging the property that f(t)f(t)f(t) is continuous. In 1−f(nt)=(1−f(t))n1-f(nt)=\left(1-f\left(t\right)\right)^n1−f(nt)=(1−f(t))n, we take t=1t=1t=1 and get:

f(n)=1−(1−f(1))n, ∀n>0f(n)=1-(1-f(1))^n,~\forall n>0 f(n)=1−(1−f(1))n, ∀n>0

f(t)f(t)f(t) is therefore an exponential function subtracted by 111, which can be represented by f(t)=1−a−λt (a>1,λ>0)f(t)=1-a^{-\lambda t}~(a>1, \lambda>0)f(t)=1−a−λt (a>1,λ>0). Substituting this form into lerp\text{lerp}lerp:

lerp(a,b,f(t))=a−λta+(1−a−λt)b\text{lerp}(a,b,f(t))=a^{-\lambda t}a+(1-a^{-\lambda t})b lerp(a,b,f(t))=a−λta+(1−a−λt)b

and this is why we choose a negative power: we would like to value to lie within (0,1)(0,1)(0,1). At each frame, we update the value of aaa using lerp(a,b,f(ΔT))\text{lerp}(a,b,f(\Delta T))lerp(a,b,f(ΔT)) where ΔT\Delta TΔT is elapsed time during this frame. As long as the FPS is stable, the result is definitely frame-independent.

Perspective #2: Solving the Differential Equation

From another perspective, we can view ata_tat​ as a function of f(t)f(t)f(t), i.e., at=lerp(a0,b,f(t))a_t=\text{lerp}(a_0,b,f(t))at​=lerp(a0​,b,f(t)) where a0=aa_0=aa0​=a is the initial value. For any ttt we can compute its value at t+Δtt+\Delta tt+Δt:

at+Δt=lerp(a,b,f(t+Δt))=lerp(at,b,f(Δt))a_{t+\Delta t}=\text{lerp}(a,b,f(t+\Delta t))=\text{lerp}(a_t,b,f(\Delta t)) at+Δt​=lerp(a,b,f(t+Δt))=lerp(at​,b,f(Δt))

which can be simplified to:

(1−f(t+Δt))a+f(t+Δt)b=(1−f(Δt))at+f(Δt)b⇒(1−f(t+Δt))a+f(t+Δt)b=(1−f(Δt))((1−f(t))a+f(t)b)+f(Δt)b⇒−(f(t+Δt)−f(t))a+(f(t+Δt)−f(t))b=(a−b)f(Δt)(f(t)−1)⇒f(t+Δt)−f(t)=f(Δt)(1−f(t))⇒f(t+Δt)−f(t)Δt=f(Δt)Δt(1−f(t))⇒f′(t)=f′(0)(1−f(t))⇒y′=λ(1−y) (λ=f′(0))\begin{aligned} (1-f(t+\Delta t))a+f(t+\Delta t)b&=(1-f(\Delta t))a_t+f(\Delta t)b\\ \Rightarrow (1-f(t+\Delta t))a+f(t+\Delta t)b &= (1-f(\Delta t))((1-f(t))a+f(t)b)+f(\Delta t)b\\ \Rightarrow -(f(t+\Delta t)-f(t))a+(f(t+\Delta t)-f(t))b &= (a-b)f(\Delta t)(f(t)-1)\\ \Rightarrow f(t+\Delta t)-f(t) &= f(\Delta t)(1-f(t))\\ \Rightarrow \frac{f(t+\Delta t)-f(t)}{\Delta t} &= \frac{f(\Delta t)}{\Delta t}(1-f(t))\\ \Rightarrow f'(t) &= f'(0)(1-f(t))\\ \Rightarrow y'&=\lambda (1-y)~(\lambda=f'(0)) \end{aligned} (1−f(t+Δt))a+f(t+Δt)b⇒(1−f(t+Δt))a+f(t+Δt)b⇒−(f(t+Δt)−f(t))a+(f(t+Δt)−f(t))b⇒f(t+Δt)−f(t)⇒Δtf(t+Δt)−f(t)​⇒f′(t)⇒y′​=(1−f(Δt))at​+f(Δt)b=(1−f(Δt))((1−f(t))a+f(t)b)+f(Δt)b=(a−b)f(Δt)(f(t)−1)=f(Δt)(1−f(t))=Δtf(Δt)​(1−f(t))=f′(0)(1−f(t))=λ(1−y) (λ=f′(0))​

Solving this differential equation we have f(t)=y=1−exp⁡(−λt−C1)f(t)=y=1-\exp(-\lambda t-C_1)f(t)=y=1−exp(−λt−C1​) where C1C_1C1​ is to be determined. Substituting f(0)=0f(0)=0f(0)=0 we solve C1=0C_1=0C1​=0. Hence the final equation for f(t)f(t)f(t) is f(t)=1−exp⁡(−λt)f(t)=1-\exp(-\lambda t)f(t)=1−exp(−λt) where λ>0\lambda>0λ>0. This aligns with the result from the first perspective.

Perspective #3: Rewriting the Naive Lerp

Actually, we can even produce the same result of f(t)f(t)f(t) from the naive interpolation formula. Starting from the naive update equation for the nnn-th frame:

an=(1−w)na+(1−(1−w)n)ba_n=(1-w)^na+(1-(1-w)^n)b an​=(1−w)na+(1−(1−w)n)b

assuming nnn is the frames per second, e.g., 303030, 606060 or 120120120. It should be particularly noticed that the unit of www is percent per frame, or %/f\text{\%/f}%/f. We would like to transform the unit of www to percent per second, or %/s\text{\%/s}%/s representing how many percentages aaa will go through towards bbb per second rather than per frame. To this end, we need to first view www in the unit of %/s\text{\%/s}%/s and multiply it with some value with unit s/f\text{s/f}s/f so that it can be used at each frame to update the input value.

The question is, what value has the unit s/f\text{s/f}s/f. Recall that the unit of nnn is f/s\text{f/s}f/s, and its inverse, which represents the elapsed time per frame, has unit s/f\text{s/f}s/f. Therefore, we just need to multiply www with the inverse of nnn, and this becomes:

an=(1−wn)na+(1−(1−wn)n)ba_n=\left(1-\frac{w}{n}\right)^na+\left(1-\left(1-\frac{w}{n}\right)^n\right)b an​=(1−nw​)na+(1−(1−nw​)n)b

where www has unit %/s\text{\%/s}%/s instead of %/f\text{\%/f}%/f. Well, (1−w/n)n(1-w/n)^n(1−w/n)n will definitely remind you of the following limit:

exp⁡(x)=lim⁡n→∞(1+xn)n\exp(x)=\lim_{n\to\infty}\left(1+\frac{x}{n}\right)^n exp(x)=n→∞lim​(1+nx​)n

If we take limits for (1−w/n)n(1-w/n)^n(1−w/n)n, the update equation now will be:

an=e−wa+(1−e−w)ba_n=\mathrm{e}^{-w}a+\left(1-\mathrm{e}^{-w}\right)b an​=e−wa+(1−e−w)b

Note that the is the update formula for one second. For one frame, we need to multiply www with Δt\Delta tΔt, the elapsed time per frame:

an=lerp(an−1,b,1−exp⁡(−w⋅Δt))a_n=\text{lerp}(a_{n-1},b,1-\exp(-w\cdot\Delta t)) an​=lerp(an−1​,b,1−exp(−w⋅Δt))

This is exactly what we’ve derived from the second perspective!

You may wonder why you cannot directly use (1−w/n)(1-w/n)(1−w/n) as the update formula, i.e. an=lerp(an−1,b,w⋅Δt)a_n=\text{lerp}(a_{n-1},b,w\cdot\Delta t)an​=lerp(an−1​,b,w⋅Δt). Of course you can do this! It’s much simpler and is more performant (not involving the exponential function), and it’s a pretty good approximation to exp⁡(−w⋅Δt)\exp(-w\cdot\Delta t)exp(−w⋅Δt). But if you want a more accurate frame-independent interpolation formula, you should use the exp⁡\expexp version.

Conclusion

In this short post, I introduced three perspectives to understand the frame-independent interpolation. Don’t get stuck with the details, just use the very neat and clean form of interpolation: the exponential function.
